# GoBroker

**GoBroker** — высокопроизводительный асинхронный сервис агрегации и стриминга финансовых котировок в реальном времени.
Приложение собирает данные из нескольких источников (Binance, MOEX, ЦБ РФ), нормализует их и доставляет клиентам через WebSockets с минимальной задержкой.

---
## 🛠 Технологический стек

* **Язык программирования:** Go (Golang)
* **Транспорт и протоколы:** gRPC, Protocol Buffers (Protobuf), WebSockets, HTTP
* **Параллелизм и конкурентность:** Goroutines, Channels, In-Memory Pub/Sub
* **Фронтенд:** Vanilla HTML5, CSS3 (CSS Grid), JavaScript (WebSocket API)
* **Стиль:** Минималистичный дизайн в стиле Go Cyan (`#00ADD8`) с кастомным маскотом Gopher

---

## 📐 Архитектура проекта

Проект построен по слоистой микросервисной архитектуре:

1. **Providers Layer (Сборщики данных):**
   * **Binance:** Интеграция Binance для получение котировок криптовалют (BTC, ETH, SOL и др.)
   * **MOEX (Мосбиржа):** Интеграция Мосбиржи для получения котировок российских акций (SBER, GAZP, LKOH и др.).
   * **CBR (ЦБ РФ):** Интеграция Центробанка для получения актуальных курсов валют (USD, EUR, CNY).

2. **Protobuf & gRPC Layer:**
   * Строгая сериализация данных с помощью **Protocol Buffers** (`.proto`).
   * Высокоскоростная передача внутренних сообщений `Quote` между модулями с низким overhead по сравнению с JSON.

3. **Broker / Hub Layer:**
   * In-memory брокер сообщений на горутинах и каналах Go (паттерн Pub/Sub).
   * Потокобезопасная обработка подписок клиентами и параллельная рассылка обновлений.

4. **Web / Delivery Layer:**
   * WebSocket-сервер для отдачи обновлений на клиент в режиме реального времени.
   * Динамический веб-интерфейс, авто-сортирующий поступающие тикеры по 3 колонкам в зависимости от провайдера (`Binance`, `MOEX`, `CBR`).

## 🚀 Инструкция по запуску

### Предварительные требования
* **Go** (версия 1.20 или выше)
* *(Опционально)* **protoc** (компилятор Protocol Buffers) — нужен только при изменении `.proto` файлов.

### Пошаговый запуск

1. **Клонируйте репозиторий:**
```bash
Клонируйте репозиторий
git clone https://github.com/pavlovvity-netizen/GoBroker.git
cd GoBroker

Установите зависимости Go:
go mod download

(Опционально, если меняли proto) Сгенерируйте Protobuf-код:
protoc --go_out=. --go_opt=paths=source_relative --go-grpc_out=. --go-grpc_opt=paths=source_relative proto/market_data.proto

Запустите приложение:
go run main.go

Откройте дашборд:
Перейдите в браузере по адресу: http://localhost:8080
```
## 💻 Веб-интерфейс

3 колонки данных: Чёткое разделение котировок по источникам (Binance, MOEX, CBR).

Живое время: Фиксация точного времени последнего обновления каждого тикера (ЧЧ:ММ:СС).

Адаптивность: Корректное отображение как на широких мониторах, так и на мобильных устройствах.
